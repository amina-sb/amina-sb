## 🚀 Featured Projects

### 🦷 AidenCare: Dental Clinic Portal
> **Problem:** Dental clinics run on fragmented, outdated tools for patient management and operations.<br>
> **Solution:** A modern, cloud-native clinic portal built by a three-person startup team.

- **Stack:** Next.js · React 19 · TypeScript · Tailwind v4 · Supabase · Vercel
- **Highlights:**
  - Production deployment on a custom domain with a Vercel CI/CD pipeline
  - Supabase (Postgres) backend with auth and a relational data model
- 🔗 [Live App](https://app.aidencare.space)

### 🛡️ HSSE Management System for an Energy Operator (NCOC)
> **Problem:** Health, Safety, Security & Environment (HSSE) processes were trapped in static Visio and Word files.<br>
> **Solution:** An enterprise SharePoint Online app that parses legacy documents and turns them into interactive, governed workflows.

- **Stack:** SPFx · React · TypeScript · SharePoint Online
- **Highlights:**
  - Parses **VSDX and DOCX** files and renders **BPMN-style swimlane flowcharts** in the browser
  - **PDF export** and **permission-based admin gating** using SharePoint groups
  - Iterated through **v2.13.3** in production use

### 🗄️ Relational Database Design & SQL Coursework
> **Problem:** Turning real-world requirements into correct, efficient relational schemas and queries.<br>
> **Solution:** A series of database projects covering schema design, normalization, and analytical SQL.

- **Stack:** SQL · PostgreSQL · Python
- 🔗 [databases-hw4](https://github.com/amina-sb/databases-hw4)
